MailMerge AI - Privacy Policy & Terms

Last updated: August 2026

1. Data Access & Scopes Requested

MailMerge AI requests access strictly limited to:

  • https://www.googleapis.com/auth/spreadsheets.currentonly: Reads recipient lead data from the currently active sheet and inserts AI-generated email subjects and body drafts.
  • https://www.googleapis.com/auth/script.external_request: Transmits prompt context and lead columns via HTTPS to OpenAI API for copywriting generation.
  • User Profile / Email: Identifies user license tiers and remaining credits.

2. Data Use Disclosure

Lead data is used exclusively to generate contextual B2B email drafts when the user clicks 'Generate Personalized Emails'.

3. Third-Party Data Sharing & Transfer

Lead row data is transmitted securely to OpenAI API endpoints via HTTPS. User data is never sold, leased, or disclosed to third parties or marketing platforms.

4. Data Protection & Security Mechanisms

Data transmission is encrypted with industry-standard TLS/HTTPS protocols. No external database stores user contact lists or sheet rows.

5. Data Retention & Deletion Policy

Zero Data Retention: All data processing is strictly ephemeral in RAM. No sheet data or drafts are saved on our servers. Access can be revoked instantly at Google Account Security.
