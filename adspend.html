AdSpend AI - Privacy Policy & Terms

Last updated: August 2026

Google Workspace API User Data Policy Compliance:
The use of raw or derived user data received from Google Workspace APIs will strictly adhere to the Google User Data Policy, including the Limited Use requirements.

1. Data Access & Scopes Requested

AdSpend AI requests access strictly limited to:

  • https://www.googleapis.com/auth/spreadsheets.currentonly: Reads ad performance metrics from the active sheet and appends calculated ROAS and AI recommendation columns.
  • https://www.googleapis.com/auth/script.external_request: Transmits ad performance row metrics via HTTPS to OpenAI API endpoints for tactical auditing.
  • User Profile / Email: Used solely to identify user credit status and license tier.

2. AI / ML Integration & Limited Use Restrictions

AdSpend AI processes marketing metrics using OpenAI API (GPT-4o-mini). In strict accordance with Google Workspace API policies:

  • No Model Training: Google user data (raw or derived) is NEVER used, transferred, or sold to create, train, or improve generalized machine learning or artificial intelligence models.
  • Ephemeral Execution: Data sent to OpenAI API is processed in real-time to generate tactical ROAS advice and is never retained.

3. Third-Party Data Sharing & Security

We do not sell, rent, or lease Google user data to any third-party advertisers, data brokers, or external entities. All data in transit is encrypted using industry-standard TLS/HTTPS protocols.

4. Data Retention & Deletion Policy

Zero Data Retention: All data handling occurs ephemerally in RAM memory. Performance metrics are purged immediately after writing insights back to the spreadsheet. Permissions can be revoked anytime via Google Account Security.
