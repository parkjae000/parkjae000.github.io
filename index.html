CleanSheet AI

An automated data cleaning, formatting, and text processing add-on for Google Sheets.

App Purpose & Overview

CleanSheet AI is an officially integrated Google Workspace add-on engineered to streamline spreadsheet workflows. It allows users to quickly format messy tables, remove duplicates, and structure unstructured textual data inside Google Sheets via secure AI processing.

Key Features & Permissions

  • Data Cleaning & Standardization: Cleans up whitespace, standardizes dates/text cases, and reorganizes raw spreadsheet inputs.
  • Scoped Access: The add-on only operates on active user selections within the current spreadsheet using minimal scope permissions (spreadsheets.currentonly).
  • Secure API Calls: Spreadsheet data sent for processing is securely transmitted in memory directly to AI endpoints strictly per user action.

Privacy Policy

CleanSheet AI respects user privacy. We do not collect, store, log, or sell any personal data, spreadsheet records, or authentication tokens. All operations are executed on-demand in temporary memory and are immediately cleared once the cleaning task is finalized.

Terms of Service
