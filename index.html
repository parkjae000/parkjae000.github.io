CleanSheet AI - Privacy Policy & Terms

Last updated: August 2026

1. Data Access & Scopes Requested

CleanSheet AI requests access strictly limited to:

  • https://www.googleapis.com/auth/spreadsheets.currentonly: Reads only user-selected cells in the currently open active spreadsheet and writes back formatted/cleaned results.
  • https://www.googleapis.com/auth/script.external_request: Sends selected text batches via HTTPS to OpenAI API endpoints for data standardization.
  • User Profile / Email (basic info): Used solely to identify user license status.

2. Data Use Disclosure

Google user data is processed exclusively in real-time to parse, clean, trim, and format spreadsheet cells upon explicit button clicks by the user.

3. Third-Party Data Sharing & Transfer

CleanSheet AI only transmits user-selected spreadsheet cell contents to the OpenAI API endpoint (https://api.openai.com/) via encrypted TLS/HTTPS for processing. We do NOT sell, rent, or transfer user data to any third-party advertisers or data brokers. OpenAI does not use data submitted via API to train models.

4. Data Protection & Security Mechanisms

All network communications are strictly encrypted using HTTPS/TLS. We do not maintain any persistent external database storing your spreadsheet data. API keys and user properties are encrypted via Google Apps Script PropertiesService.

5. Data Retention & Deletion Policy

CleanSheet AI operates on a zero-retention architecture. User spreadsheet data is processed ephemerally in memory and is deleted immediately after the cleaned values are written back to your spreadsheet. Users can completely revoke access at any time via Google Account Permissions.
