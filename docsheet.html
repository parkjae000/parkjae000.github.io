DocSheet AI - Privacy Policy & Terms

Last updated: August 2026

1. Data Access & Scopes Requested

DocSheet AI requests access strictly limited to:

  • https://www.googleapis.com/auth/spreadsheets.currentonly: Reads unstructured invoice/receipt text dumps from the active sheet and inserts extracted structured tables (8 columns).
  • https://www.googleapis.com/auth/script.external_request: Transmits document text via HTTPS to OpenAI API endpoints for parsing.
  • User Profile / Email: Used solely to identify user credit status and license verification.

2. Data Use Disclosure

User document data is processed exclusively in real-time to convert unstructured receipt/invoice text into structured tabular data upon user command.

3. Third-Party Data Sharing & Transfer

Document text is transmitted securely to OpenAI API endpoints via TLS/HTTPS. We do NOT sell, lease, or share user data with advertisers or data brokers.

4. Data Protection & Security Mechanisms

All data in transit is encrypted using HTTPS/TLS. No external database stores user document contents or sheet rows.

5. Data Retention & Deletion Policy

Zero Data Retention: Processing is completely ephemeral in RAM. All data is deleted immediately after the extracted table is written to the spreadsheet. Permissions can be revoked anytime via Google Account Permissions.
