DocSheet AI - Privacy Policy & Terms

Last updated: August 2026

1. Introduction

DocSheet AI ("we", "our", or "the Add-on") is a productivity tool designed for Google Sheets that automates the extraction and parsing of unstructured invoice and receipt text into structured spreadsheet tables using AI processing.

2. Google User Data & Scopes

DocSheet AI accesses Google user data strictly necessary to provide its core functionality. We adhere strictly to the Google API Services User Data Policy, including the Limited Use requirements.

  • https://www.googleapis.com/auth/spreadsheets.currentonly: Used solely to read selected/active raw invoice text and write extracted table data into the user's currently opened Google Spreadsheet upon explicit user action.
  • https://www.googleapis.com/auth/script.external_request: Used solely to send raw text snippets via HTTPS API calls to OpenAI endpoints for data structuring.
  • User Profile / Email (basic identity): Used solely for identifying user subscription tier and credit quotas.

3. Data Handling & Security

DocSheet AI does not sell, lease, or store your private spreadsheet data on third-party servers. All document processing is ephemeral and executed securely via encrypted TLS connections directly to AI inference models. We never use customer data to train generalized AI models.

The service is provided "as is" without warranty of any kind. Users are responsible for reviewing extracted financial data for accuracy prior to official bookkeeping or filing.
