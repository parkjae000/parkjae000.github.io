DocSheet AI - Privacy Policy & Terms

Last updated: August 2026

Google Workspace API User Data Policy Compliance:
The use of raw or derived user data received from Google Workspace APIs will strictly adhere to the Google User Data Policy, including the Limited Use requirements.

1. Data Access & Scopes Requested

DocSheet AI requests access strictly limited to:

  • https://www.googleapis.com/auth/spreadsheets.currentonly: Reads unstructured invoice/receipt text dumps from the active spreadsheet and inserts structured 8-column table rows.
  • https://www.googleapis.com/auth/script.external_request: Transmits document text via HTTPS to OpenAI API endpoints for parsing.
  • User Profile / Email: Used solely to identify user license status and credit balance.

2. AI / ML Integration & Limited Use Restrictions

DocSheet AI processes user text batches using OpenAI API (GPT-4o-mini). In strict accordance with Google Workspace API policies:

  • No Model Training: Google user data (raw or derived) is NEVER used, transferred, or sold to create, train, or improve generalized machine learning or artificial intelligence models.
  • Ephemeral Execution: Data sent to OpenAI API endpoints is processed solely in real-time to generate structured outputs and is not retained for training.

3. Third-Party Data Sharing & Security

We do not sell, rent, or lease Google user data to any third-party advertisers, data brokers, or external entities. All data in transit is encrypted using industry-standard TLS/HTTPS protocols.

4. Data Retention & Deletion Policy

Zero Data Retention: All data handling occurs ephemerally in RAM memory. Document text is purged immediately after the parsed table is written to the user's active spreadsheet. Users can revoke add-on permissions anytime via Google Account Security.
